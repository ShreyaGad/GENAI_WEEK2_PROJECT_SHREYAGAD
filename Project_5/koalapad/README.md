# KoalaPad

KoalaPad is a cozy, local-first notebook for turning typed personal notes into hand-drawn-looking pages. It is the Project 5 build, **Scribbly Notes**.

## Open it

Open `index.html` in a modern browser. No install, account, server, Wi-Fi, or API key is needed. Your notes are saved in this browser's local storage on this device. Clearing browser site data also clears the saved notes, so export anything you want to keep.

## What is here

- Home, Note Studio, My Notebooks, and Sticker Garden pages with in-app navigation.
- Create folders, filter the notebook shelf by folder, and move a note between folders from Note Studio.
- A live canvas notebook preview with Soft, Bouncy, and Tidy handwriting feels, single or mixed ink colors, ruled/grid/dotted/blank paper, four text sizes, and adjustable word-level variation.
- Pen, marker, pencil, bold, and selection highlighter tools.
- Draw with mouse, touch, or a pressure-sensitive tablet stylus. Change the brush width, move stickers by dragging them on the page, and remove stickers from the page's sticker list.
- Line-aware wrapping and page flow. The preview, image export, PDF export, and print flow use the same complete-line pagination.
- Download each note as page PNGs or as a multi-page PDF; browser print can also print the pages.
- Stickers, decorative page details, gentle transitions, and Koji, a small offline helper with revision and study-break prompts.

All application code and tools are local. The app does not fetch font files or make network requests, so it continues to work with Wi-Fi off. The handwriting look uses locally available system cursive fonts with offline fallbacks and adds slight per-word variation. Exact lettering can vary by device; to keep it consistent, add a properly licensed handwriting font file to an `assets/` folder and define it with `@font-face` in `styles.css`.

KoalaPad is for personal notes and revision only. Do not submit pages generated by KoalaPad as handwritten schoolwork.
