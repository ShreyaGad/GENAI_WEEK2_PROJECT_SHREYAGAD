Prepare your photo and signature

  • Choose a recent, clear photo with your face visible and a separate signature scan.
  • Select the exam or job form preset that matches your application.
  • In the studio, drag the crop frame to position it. Use the size slider to zoom the crop.
  • Switch between Photo and Signature tabs, then prepare the image files.
  • Review the preview, pixel dimensions and exact KB size. Download each JPG or both together as a ZIP.

What happens to your files?

AuraForm uses the browser’s image decoder, canvas and local file APIs. Selected files are kept in this browser’s local IndexedDB so they can move from the upload page to the studio. Image processing happens on your device. The page does not send image data to a server or third-party image service.

For offline use, open AuraForm once while it is available, then disconnect from Wi-Fi and continue. Keep the original photo and signature; preparing an output does not alter them.

Questions, answered.

Quick notes for application day.

Will AuraForm guarantee the application accepts my image?

No tool can guarantee acceptance. Each portal may check clarity, pose, date, background, signature format, and other rules in addition to file size and pixel dimensions. Use the linked official notice and inspect the portal’s final preview.

Why does a preset say “AuraForm dimensions”?

Some official notices specify only JPG/JPEG and a file-size range, without exact pixel dimensions. The tool still needs pixels to create a file, so it uses practical export dimensions and labels them as its own defaults.

Why might my file be below the minimum KB size?

Simple images (especially signatures on white paper) can be smaller than a portal’s minimum. AuraForm preserves the stated pixel dimensions and tells you when the output is below the minimum. You can use the original scan or check the portal’s current instructions; do not add visual noise merely to inflate a file.

What image types can I use?

Common browser-readable JPG, PNG and WebP images are supported. Outputs are JPG. Very large images are limited to 25 MB per input file so local processing stays manageable.
