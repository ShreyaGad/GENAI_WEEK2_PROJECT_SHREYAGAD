# KoalaPad build prompts

## 1. Initial project prompt

Build Project 5, Scribbly Notes, as a local-first web app called KoalaPad. Turn typed personal notes into pleasant hand-drawn notebook pages. Include a live preview, three handwriting styles, ink and paper choices, natural word-level variation, long-note page flow that never splits a line, PNG and PDF export, and offline behavior. Add a cute koala assistant, multiple navigable pages, stickers, brush and highlighter tools, font sizing, a blue/green/white/beige theme, gentle animation and a clear personal-use reminder. Keep the app easy to open and use.

## 2. Implementation prompt

Create KoalaPad as a self-contained HTML, CSS, and JavaScript app in this folder, with Home, Note Studio, My Notebooks, and Sticker Garden pages. Keep notes in browser local storage, avoid remote services, and add a readable README. Render notes into canvas pages and export the same pages as PNG images and a multi-page PDF. Keep related lines together on each page and use pleasant, responsive styling.

## 3. Feature improvement prompt

Fix sticker placement and removal, add folders and page-type choices for blank, grid, and ruled paper, allow more than one ink color on a note, keep the app usable with Wi-Fi off, and support drawing with a tablet stylus.
