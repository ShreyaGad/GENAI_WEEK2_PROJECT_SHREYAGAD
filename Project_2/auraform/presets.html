How to read these presets

Photo and signature sizes are listed separately because application portals often set different limits for each.

Exact pixel dimensions

The UPSC recruitment FAQ below includes exact pixels. JEE Main and NEET 2026 specify the required file sizes and image guidance, but the cited bulletin does not give pixel dimensions for the uploaded image. AuraForm defaults to 600 × 800 px photo and 600 × 250 px signature in those presets.

File-size compression

AuraForm exports JPEGs and searches for the highest image quality that remains under the maximum. If an official minimum cannot be met, it will say so rather than disguising the size.
