# One Page Revision skill

This reusable Codex skill turns a supplied textbook chapter or excerpt into a compact, exam-focused revision sheet. It is designed to work from an explicit `$one-page-revision` invocation or automatic skill discovery when the request clearly matches.

## Install for a fresh session

1. Unzip `one-page-revision.zip`.
2. Copy the `one-page-revision` folder into your Codex skills directory: `%USERPROFILE%\.codex\skills\` (create `skills` if needed).
3. Start a new Codex session. Invoke it with `$one-page-revision` and attach or paste the chapter.

The skill returns Markdown in chat by default. Ask for a PDF or document if you want a downloadable sheet.

## Try it

`$one-page-revision Turn this chapter into a one-page revision sheet: [paste or attach chapter]`
