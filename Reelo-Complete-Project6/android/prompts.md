# Reelo build prompts

1. Build a native Android app called Reelo for Project 6: a cute purple floating monster for Instagram Reels and YouTube Shorts. Include manual counting, a movable overlay, offline persistence, daily count, estimated time and seven-day history.
2. Add an optional automatic mode using Android AccessibilityService events scoped to Instagram and YouTube. Do not inspect screen text or collect message/content data. Clearly label automatic counts as estimates because scroll events are not guaranteed to equal watched videos.
3. Test installation, overlay permission, manual counting, persistence across restart, and automatic event counting on a real Android phone. Fix any compile/runtime issues and document device-specific steps.
